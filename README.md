# Calculateur de table élévatrice

Une page statique qui reprend le formulaire avancé fourni (corrigé) et ajoute une mise en page moderne avec carousel, calculs instantanés et récapitulatif imprimable.

## Utilisation
1. Ouvrez `index.html` dans votre navigateur.
2. Renseignez les champs du formulaire (données de charge, géométrie, hydraulique et contact).
3. Cliquez sur **Calculer et enregistrer** : le pré-dimensionnement est affiché immédiatement, prêt à être imprimé ou partagé.
4. Utilisez **Nouvelle demande** pour réinitialiser et saisir un autre cas.

## Contenu
- `index.html` : structure HTML et sections principales (héros, formulaire, résultats, pied de page).
- `styles.css` : thème modernisé, grille responsive, cartes et composants.
- `app.js` : carousel d'illustrations, logique de calcul et génération dynamique du récapitulatif.

Les calculs restent indicatifs et se basent sur les paramètres saisis (pression max, charge utile, rendement, etc.).

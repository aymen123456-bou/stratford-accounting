# Stratford Accounting landing page

A modern, single-page marketing site for Stratford Accounting featuring a hero banner, services overview, client roster, and contact details.

## Project structure
- `index.html` — main landing page markup.
- `styles.css` — styling for layout, typography, and responsive behavior.

## Getting started
1. Open `index.html` directly in your browser, or serve the folder locally:
   ```bash
   python -m http.server 8000
   ```
2. Visit `http://localhost:8000` to view the site.

## Customization tips
- Update company information, services, or clients directly in `index.html`.
- Adjust colors and spacing in `styles.css` using the CSS variables defined at the top of the file.
